Website for Heather's bookkeeping business (Grey Owl Bookkeeping based on repo name).

**Target clients:** Non-profits, small-to-medium businesses whose owners want to offload bookkeeping. They want education and hand-holding.

**Key features:**
- Social proof / testimonials (placeholder for now)
- Client questionnaire (detailed intake form)
- Personal tax client dedicated page
- Funnel from social media presence
- Proprietary software offering - saves up to $3000/yr on bookkeeping software (vs QuickBooks etc.)

**Color palette (pastels):** #21204c (dark navy), #d4c2ef (lavender), #c8ce8e (sage green), #fff7ae (soft yellow), #f3c0f2 (pink)

**Tech stack:** Next.js, static site

**Why:** Drive social media traffic to website for lead generation and client onboarding.
**How to apply:** Focus on trust-building, education-oriented copy, easy questionnaire flow.
